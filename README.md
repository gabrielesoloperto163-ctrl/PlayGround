## The Sunken Kiln

A small 3D clay-platforming chapter: pulse the basin to raise nearby stepping stones, hop across the causeway, collect all three kiln embers, and reach the gate. Watch for the roaming siltling.

- **Move:** WASD or arrow keys
- **Hop:** Space
- **Clay pulse:** E
- **Touch:** on-screen movement, hop, and pulse controls

Serve this folder with any static web server and open `index.html` (for example, `python3 -m http.server 3002`). Three.js is loaded from jsDelivr.
