## Run locally

This is a static browser game. From the project directory, start any local HTTP server, for example:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>. Internet access is needed to load Three.js and the web fonts from their CDNs.

## Controls

- **WASD** move, **mouse** look, **Shift** sprint
- **E** interact with objectives or report a nearby body, **R** report, **Q** emergency meeting (crew) / sabotage (impostor)
- **Left click** fire as crew, **F** strike as impostor, **G** sabotage
- **Esc** pause; touch controls are available on small/coarse-pointer screens
